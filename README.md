# SB Coaching – hemsida

Fristående statisk webbplats med separata sidor, bilder, träningsvideo och det befintliga Google-formuläret.

## Förhandsvisning
Öppna index.html i en webbläsare. För full funktion, publicera hela mappen med undermappen assets på ett webbhotell.

## Videon
Startsidan använder assets/sb-coaching-training.mp4 som en tyst, loopande bakgrundsvideo. Ljudet är avstängt eftersom webbläsare normalt kräver det för automatisk uppspelning.

## Sidor
- index.html – startsida
- traning.html – träningsupplägg
- camper.html – camper och bilder
- om-oss.html – tränarna
- priser.html – prisförfrågan
- kontakt.html – kontaktuppgifter
- anmalan.html – befintligt Google-formulär

Allt bildmaterial i assets hämtades från SB Coachings GitHub-repository. CNAME är inte inkluderad i paketet, så publicering byter inte domäninställningar automatiskt.
